# Slice 6: Reversible Multiscale Graph

**Status: Complete — 2026-07-23.**

## Frame

Let the operator see concrete connected components and an execution-inert
aggregate view, then move between them at the same causal event without losing
the route to exact evidence.

## Constraints

Use the two existing grounded scenarios and authored analytical boundaries.
Do not infer organizations, add aggregate actors, mutate canonical state,
introduce a graph dependency, redesign the simulator, or attempt general
nested/overlapping boundary semantics.

## Modality

Boundary membership, route coarsening, event attribution, revision binding,
non-execution, and loss accounting are deductive. Whether the connected graph
and scale transition are understandable is exploratory; browser inspection
must show whether an operator can explain a coarse event by stepping down once.

## Slice Contract

- **Vertical scope:** open retained run → select event → view connected exact
  graph → collapse one authored boundary → inspect derived aggregate state and
  trace → expand to exact members at the same revision.
- **Success:** aggregate nodes and routes contain only derived member evidence;
  boundary mode reports hidden member/route/fact/information counts; event focus
  maps to the aggregate; expansion preserves the selected event and revision;
  no boundary can appear in an action, mechanism, or canonical patch.
- **Audit:** forged aggregate state, future-state leakage, boundary/runtime ID
  collision, missing members, crossing-route misclassification, internal-route
  double counting, events with no visible member, protected-data leakage,
  aggregate execution, hostile labels, resize/reopen behavior, and empty
  boundary projections.
- **Cleanup:** keep one common boundary projector and one graph-render path;
  remove the separate route-pill-as-graph implication while retaining a compact
  route readout as supporting evidence.
- **Done when:** projection and browser gates pass, exact prior behavior
  regresses cleanly, every finding is dispositioned, the concern register is
  triaged, and the accepted commit is pushed and deployed.
